# INC-2026-008 M-01 spindle current alarms after a program update — feed rate doubled

SYNTHETIC DOCUMENT (FabPilot demo). Author: shift technician, K.M.

## 1. Summary

After a program update, M-01 showed spindle current alarms with the spindle slowing down in the
roughing cycle. The spindle drive was suspected first because M-01's spindle had been exchanged in
2023. The new program had a doubled feed rate. Program corrected before the relay tripped.

## 2. Timeline

- 14 Jul, 22:00: updated program released.
- 14 Jul, 22:30–23:50: `CURR-HIGH` on `spindle_motor_current` (40–45 A) in each roughing pass,
  `spindle_speed` sagging during the passes.
- 15 Jul, 07:00: spindle drive diagnosis requested. Drive parameters and encoder checked: fine.
- 15 Jul, 09:30: comparison with the previous program version: roughing feed 0.24 instead of 0.12.
- 15 Jul, 10:00: program corrected; current back to 25–30 A.

## 3. Evidence

- Current up while speed down, only in the roughing cycle of the updated program.
- `spindle_vibration` and `spindle_bearing_temp` normal; the drive had no fault codes.
- The alarms started within 30 min of the program release.

## 4. Root cause

Programming error in the update (feed value doubled), not a machine fault.

## 5. Corrective actions

- Program corrected; four-eyes check for feed and speed changes in released programs.

## 6. Lessons learned

"What changed just before the alarms started?" A program release is a change, like a tool change or
a material change. The previous spindle repair was a red herring.
